# Product thesis and comparison

Reviewed public primary product documentation on 2026-10-11. Statements below are
vendor-documented offerings, not independently verified behaviour or speed. No paid
account, private dataset, copied proprietary rules or vendor UI assets were used.
Source IDs/URLs/review limits resolve in [sources](../data/sources.json).

| Product / source                  | Documented baseline                                                                                     | Workbench response                                                                                                                                                                                     |
| --------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Screaming Frog / frog             | HTTP/JS crawl, redirect/meta/link/duplicate analysis, integrations, comparisons, CLI scheduling, AI     | Match core crawl/evidence workflows over time. Comparison and rendering are baseline expectations, not differentiation. Integrate future imports rather than recreate its entire extraction ecosystem. |
| Sitebulb / sitebulb, sitebulb-mcp | Categorised priorities/explanations, rendering, structured data/performance, comparisons and MCP access | Inspectable guidance and MCP are established. Workbench aims for local explicit intent, immutable observations and guarded verification. No superiority claim.                                         |
| Ahrefs / ahrefs                   | Technical/on-page categories, JavaScript, prioritisation and vendor health summaries                    | Use explicit outcomes and known denominators. Do not imitate or claim its independently collected backlink/keyword datasets. Advertised throughput untested here.                                      |
| Semrush / semrush                 | Site Audit technical/on-page and performance views; related keyword, backlink and AI products           | Complement supported provider evidence/imports. Avoid inventing demand, authority or AI-visibility scores. No private API capability assumed.                                                          |

The thesis is a transparent local decision/remediation loop: immutable capture →
source-linked check → approved intent → grouped handoff → compatible fresh recheck.
It needs independent usefulness/false-positive evaluation before a market claim.
JavaScript execution and MCP alone are not differentiators. A crawler cannot replace
engine-selected canonical/index observations, a global backlink index, comprehensive
keyword database, market-specific SERP observation or business analytics.

Intentionally not built: multi-tenant SaaS, global search/backlink index, search-engine
scraping/evasion, mass publishing, automatic content deletion, arbitrary agent shell
commands, guessed ranking/revenue uplift, universal SEO or AI authority score.
Optional integrations must preserve their scope/quotas/provenance and remain optional.
See capabilities and task traceability for implemented versus pending work.
