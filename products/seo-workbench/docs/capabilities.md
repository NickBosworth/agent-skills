Owner-normalised Bing, analytics, aggregate access-log and third-party crawl JSON
imports are implemented with bounded UI/CLI/HTTP/MCP record reads, provenance,
unknown metrics and shareable redaction. They are not live adapters or direct vendor
CSV/database/raw-log readers. See [site-data](site-data.md).

No release, public push, private account use, paid service or live website modification
was authorized for this task. No claim of market superiority, indexing, ranking gains,
WCAG certification or exhaustive security assurance is made.

Trusted embedding extractors now have explicit prerequisites, bounded JSON output,
detached capture inputs, deterministic versioned records and resume manifests.
Private page/report reads preserve their facts; shareable reports omit them.
Standard CLI/HTTP/MCP configuration cannot load extractor code. The deterministic
provider example verifies an interface, not live model quality. See
[extensions](extensions.md).
