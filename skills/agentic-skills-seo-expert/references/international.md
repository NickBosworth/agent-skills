# International and multilingual SEO

## Establish market intent
Inventory languages, regional differences, currencies, delivery/service coverage and existing URL strategy. A language translation and a market-specific version are not the same thing. Preserve the project’s stable domain/subdomain/subdirectory choice unless evidence justifies a migration; no structure is universally best for every business.

## Discoverable versions
Use stable distinct URLs for versions users need to reach. Ensure visitors and crawlers can discover alternatives without compulsory geo/IP redirects. A user should be able to choose a different region or language when appropriate. Cookie-based preferences must not make the only meaningful content inaccessible to a fresh direct request.

## Hreflang audit
Inspect the complete reciprocal set, self references, supported language/region values, fully resolved target URLs, status, indexing intention and canonical consistency. `x-default` can represent a fallback/selector when that matches the implementation; it is not a requirement for every cluster. Do not combine incompatible or stale alternate sets generated by separate plugins. [G17]

Hreflang relates genuine alternatives; it is not a substitute for translation or canonicalisation. Distinct translated pages should not all canonicalise to the source-language page merely to silence a duplicate-content tool. Review same-language regional duplicates in context rather than issuing a universal canonical rule. [G10, G17]

## Localised content research
Research audience wording and search results in the target language and market. Do not simply translate English keyword volumes or assume a literal translation expresses local intent. Record location/tool limitations and use a qualified language reviewer for important copy. Match measurements, dates, pricing, delivery terms and examples to the genuine offering.

## Delivery checks
Test direct URL entry, selector navigation, query parameters, fallback language, mobile variants and edge/CDN caching. A cache-key error that serves one region’s price or metadata to another is both a user and discovery problem. Confirm language metadata and visible text match the route; flags are not a substitute for accessible language labels.

## Rollout
Start with a representative locale/template combination and validate route generation, canonical/hreflang output and actual content. Expand only when the translation, support and commercial operation can sustain it. Automatically creating hundreds of shallow locale pages without real localisation does not satisfy a user need. [G02]

Deliver the locale inventory, alternate-cluster matrix, evidence gaps, localised briefs and staged verification/rollback plan. Country-specific feature eligibility must be rechecked in current engine documentation.

Sources: G02, G10, G17. The rollout and research checks are operational recommendations.
