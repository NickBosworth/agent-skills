# Source register

Research snapshot: **10 October 2026**. This pack is an original operational synthesis, not a documentation mirror. `reviewed` means relevant content was retrieved and considered, not that every paragraph was exhaustively audited. Source updates can supersede this snapshot.

Engine specifications and policies outrank vendor heuristics. A source supports the bounded rule cited beside it, not every judgement in this pack. Commercial publishers describe their own methods; proprietary metrics are not engine metrics.

Bing’s principal Webmaster Guidelines page returned only a JavaScript shell. It is explicitly **access-limited**, not silently counted as reviewed. Accessible official Bing articles support the included Bing workflows; policy-sensitive work must re-open the guidelines using the host browser.

## How to use sources

Before a consequential or feature-specific recommendation, open the cited canonical page, record the section and review date in the engagement’s evidence log, and verify that it applies to the engine, market, page type and tool version. If the page cannot be read, mark the claim unverified and do not invent its contents.

Do not paste private exports into issue trackers or commit credentials. Keep project observations outside this public source register. Provider access terms, trademarks and third-party copyrights are unaffected by the pack’s licence.
