# Visual direction

Establish reading order, dominant action, groups, density, type roles, color roles,
asset use and motion purpose. Inspect the existing system before inventing tokens.
Use a small coherent set of roles; exceptions need a task reason.

Compare structurally different directions only when direction is actually open.
Faithful implementation of an approved reference does not require another redesign
interview. Fit representative copy into the composition before polishing.

Look for competing primary actions, unrelated decorative motifs, weak alignment,
ambiguous grouping, unreadable type, inconsistent assets and motion that obscures
state. Explain observable user consequences rather than declaring common fonts,
cards, gradients or frameworks inherently bad. Originality without utility is not
quality. Do not invent public proof or customer logos to make a page feel finished.
