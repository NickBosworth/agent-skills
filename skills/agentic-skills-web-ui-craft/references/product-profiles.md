# Product profiles

Choose density and expression from the actual task, not a universal premium style.

| Product | Prioritize | Stress case |
| --- | --- | --- |
| Marketing | Clear offer, truthful proof, useful action | Long headline, no fabricated metrics |
| Dashboard | Comparability, units, freshness, operations | Missing/stale data and large tables |
| Ecommerce | Price/availability clarity, safe purchase | Invalid quantity, stock change, payment failure |
| Forms/portals | Labels, recovery, progress and permission | Expired session and preserved valid input |
| Editorial | Readability, navigation, attribution | Long content, zoom and narrow viewport |
| Developer tools | Accurate state and actionable errors | Partial operation, retries and destructive effects |

A dense screen may be appropriate when experts compare many values. A sparse hero
may be appropriate when one choice matters. Preserve familiar interaction patterns
unless observed user needs support an alternative. Do not replace game-interface
workflows with web marketing patterns; use the actual platform and player context.
