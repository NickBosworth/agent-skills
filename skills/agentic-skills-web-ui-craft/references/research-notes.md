# Provenance and evidence boundaries

The core workflow is retained from the original package. Supporting material was
newly authored on 2026-10-10 because the available copies were incomplete. The
unavailable 96-item catalogue and optional helper suite are not represented as
recovered, executed or shipped. This package instead provides focused references,
original diagnostic examples, templates and behavioural scenarios.

Primary references consulted for the reconstructed guidance:

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/): scoped accessibility criteria.
- [WAI-ARIA APG](https://www.w3.org/WAI/ARIA/apg/patterns/): widget patterns.
- [Web Vitals](https://web.dev/articles/vitals): measurement and field/lab boundaries.
- [Agent Skills specification](https://agentskills.io/specification): package format.

The workflow, profiles and diagnostic examples are engineering/design synthesis.
They are not validated research findings or universal standards. Linked material
remains owned by its authors; no third-party manual, font or article is bundled.
Verify changing framework APIs and formal requirements against current sources.
Behavioural scenarios are defined, not completed model benchmarks.
