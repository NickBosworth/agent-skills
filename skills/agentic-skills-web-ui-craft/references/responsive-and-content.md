# Responsive content

Design for content and available space rather than a list of fashionable device
sizes. Inspect narrow and wide layouts, zoom, long labels, translated copy, large
numbers, empty datasets, dense tables and absent imagery. Preserve the reading and
focus order when columns collapse.

Use intrinsic sizing and established layout primitives. Avoid fixed heights that
clip content, viewport-width overflow, overlays covering actions, and text truncation
that hides needed decisions. A scrollable table can be appropriate when its purpose
requires two-dimensional comparison; make the affordance and row context usable.

Verify touch and keyboard interaction as well as pixels. Font loading, image ratio,
content changes and pending states should not unexpectedly move an intended click
or the primary task. Do not claim emulation proves a physical device's behaviour.
