# Architecture decision record template

Adapt to the repository's existing format. Keep proposed and accepted states distinct.
Remove template instructions and unused fields before saving.

```text
ID and title:
Status: proposed / accepted / deferred / superseded
Scope:
Context and evidence:
Problem and relevant quality goals:
Options considered, including the simpler alternative:
Recommendation and reason:
Accepted choice and authority (only when established):
Consequences, costs and constraints:
Project rule and its canonical location:
Verification and limits:
Current adoption, debt and scoped exceptions:
Migration/rollback implications:
Reconsider when:
Supersedes / superseded by:
```

Acceptance is a design decision. Track implementation and verified enforcement
separately; do not infer them from the ADR's status.
