# Add Awesome Copy

## Outcome and acceptance

Add the requested `agentic-skills-awesome-copy` package under `skills/`. Research
primary writing guidance and model-style evidence; synthesize original, useful
instructions for titles, body copy and product text. Preserve facts, author voice,
genre and user authority while diagnosing generic writing habits in context.
Register the package and provide meaningful positive, negative and failure scenarios.

## Scope and decisions

The initial package is version 1.0.0 under CC0-1.0. It contains a concise entrypoint,
two focused editorial guides, a research reference covering 14 primary sources,
11 synthetic worked examples, branded adapter metadata and 28 defined behavioral
scenarios. It has no executable helper, detector service or rigid word blacklist.
Naturalness and reader preference are editorial outcomes; structural tests cannot
prove them. The research includes limits and counterevidence rather than treating
all assisted writing as homogeneous.

Integration covers the catalogue, library chooser, package count, migration note,
overlap guidance, maintainer review hashes and verification record. Existing package
versions and SEO/SVG inventories need no content changes. Release tooling discovers
canonical package folders and generates its own checksum inventory. No public push,
release, global installation or changes to the executable product are authorized
by this task. Preserve unrelated work already present in the checkout.
