1. **Conditional guidance and routing.** Add practical refactoring, Options/NRT,
   test-platform and performance guidance. Preserve required core rules; keep
   specialist detail conditional. Add positive/negative scenario definitions for
   each changed decision. Update callers, package version, catalogue and changelog.
2. **Executed contract fixtures.** Compile and run nullable helpers and Options
   lifetime/reload/validation checks. Prove removed nullable annotations produce
   the expected compiler diagnostics. Exercise rename collision, partial/generated
   input ownership, external names and conditional compilation with preserved
   behavior. Add bounded revision-bound red/green evidence for a genuine defect.
   Use separate disposable workspaces and independent expected outcomes.
3. **Runner diagnosis and verified MTP.** Distinguish test framework, effective
   execution platform and command mode. Keep unsupported configurations explicit.
   If extending the helper, preserve VSTest calls and execute real MTP success,
   failure and empty/skipped evidence cases before claiming support.
4. **Controlled evaluations.** Provide reproducible neutral synthetic task inputs,
   independent outcome checks and a paired with-skill/no-skill protocol. Execute
   repeated matched runs with recorded model/settings, exposure controls, time
   and token usage when available. Include no-op and nonactivation controls.
   Publish only reviewed aggregate evidence; definitions and unavailable metrics
   are not executed results. Do not require wins or tune away baseline successes.
5. **Final integration and audit.** Run package/helper/SDK gates, official creator
   validation, full library gates, actual-index and history privacy checks,
   redacted Gitleaks and temporary archive extraction checks. Inspect the final
   diff and document evidence against every criterion. Remote CI, native discovery
   and other hosts remain unverified unless actually exercised.
